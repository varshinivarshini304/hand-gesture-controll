# ✋ Hand Gesture Control System

A real-time hand gesture recognition system that enables users to control their computer using hand movements and gestures through a webcam. The project uses Computer Vision and Machine Learning techniques to replace traditional mouse and keyboard interactions.
## 📹 Live Demo

[![Watch Demo](https://github.com/yourusername/project/blob/main/website.png?raw=true)](https://github.com/varshinivarshini304/hand-gesture-controll/blob/main/Hand%20Gesture.mp4)
## 🚀 Features

* 🖱️ Cursor movement using hand tracking
* 👆 Left click gesture
* 👉 Right click gesture
* ✊ Drag and drop functionality
* 📜 Scroll up and scroll down
* 🔊 Volume control
* 🔍 Zoom in and zoom out
* 🪟 Minimize all windows
* 🎯 Smooth cursor movement with filtering
* ⚡ Real-time gesture recognition
* 📹 Live webcam processing
* 🛡️ Mouse failsafe protection

## 🧠 Gesture Mapping

| Gesture                       | Action           |
| ----------------------------- | ---------------- |
| Index Finger                  | Move Cursor      |
| Thumb + Index                 | Left Click       |
| Hold Thumb + Index            | Drag             |
| Thumb + Middle                | Right Click      |
| Index + Middle                | Scroll Up        |
| Thumb + Index + Middle        | Scroll Down      |
| Index + Middle + Ring         | Zoom Out         |
| Thumb + Index + Middle + Ring | Zoom In          |
| Pinky Finger                  | Volume Down      |
| Thumb Finger                  | Volume Up        |
| Closed Fist                   | Minimize Windows |
